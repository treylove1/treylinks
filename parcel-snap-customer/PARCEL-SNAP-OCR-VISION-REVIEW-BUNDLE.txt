PARCEL SNAP — OCR / KNOWN-CUSTOMER / VISION INDEPENDENT REVIEW BUNDLE
Generated: 2026-10-01

PURPOSE
Parcel Snap is warehouse software. A worker photographs a package label. The software must:
1. identify a known customer/person/business if possible,
2. capture tracking/carrier/address,
3. save the package/photo,
4. notify the correct customer,
5. NEVER invent a customer identity from OCR noise.

CURRENT DESIGN
A. KNOWN-CUSTOMER MATCHER (primary truth check)
- The company's directory is the list of identities Parcel Snap is allowed to auto-match.
- Each customer can be PERSON or BUSINESS.
- Each customer can have aliases: PERSON_NAME, BUSINESS_NAME, LABEL, CUSTOMER_CODE.
- OCR/vision output is searched for those known identities.
- Exact, compact, partial, and fuzzy evidence are scored.
- Return-address context is penalized.
- Destination/business+person context is boosted.
- Business alias alone is not enough to turn a PERSON account into a match.
- Low confidence => REVIEW or NO_MATCH, not invented identity.

B. VISION LAYER
- Server-side multimodal endpoint is designed to inspect the whole image.
- It must distinguish carrier, sender/return address, recipient, destination, tracking.
- It must return structured JSON and needs_review.
- It must not invent a full person name when text is incomplete.
- Vision endpoint currently requires external model credentials before real inference can run.

C. OCR FALLBACK
- Browser Tesseract remains supporting evidence / fallback.
- Real Roadie package OCR was poor:
  "Your electconic needs Trevor"
  "16600 Ni S4TH AVE UNIT 9"
  "HIALEAH FL 33014-6110"
- Directory-first matching still resolves that to known customer "Trevon Humes"
  because the same line contains a strong fuzzy business anchor "Your Electronic Needs"
  plus a fuzzy known first-name match "Trevor" ~= "Trevon".
- This exact case is now a regression test.

D. SAFETY / FAILURE RULE
When no known identity is sufficiently supported:
- do not auto-select a customer,
- show manual Name + Email + Phone/WhatsApp fields,
- worker confirms/creates the customer,
- that customer becomes available for future matching.

IMPORTANT QUESTIONS FOR INDEPENDENT REVIEW
1. Can the matcher false-match two customers who share the same business prefix?
2. Are the 0.90 auto-match / 0.72 review / 0.08 margin thresholds appropriate?
3. Is business+known-first-name enough for automatic selection, or should it be REVIEW?
4. How should suite/unit/customer codes be weighted versus names?
5. Should destination-address evidence be used more strongly?
6. How should labels with no human name but only business name be handled?
7. How should multilingual names / accents / OCR confusions be normalized safely?
8. Is browser-side Tesseract too slow for a 100-package warehouse line?
9. Should the multimodal model be given the entire known-customer directory, or only likely candidates?
10. What adversarial label cases could cause one customer's package to be assigned to another?

(() => {
  const VISION_API = SUPABASE_URL + "/functions/v1/parcel-snap-vision";

  async function analyzePackageWithVision(imageDataUrl) {
    const { data: { session } } = await sb.auth.getSession();
    if (!session) return null;

    const response = await fetch(VISION_API, {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        "Authorization": "Bearer " + session.access_token,
        "apikey": SUPABASE_KEY
      },
      body: JSON.stringify({ image_data_url: imageDataUrl })
    });

    const data = await response.json().catch(() => ({}));
    if (response.status === 503 && data.error === "VISION_NOT_CONFIGURED") return null;
    if (!response.ok) throw new Error(data.error || "Vision analysis failed");
    return data.result || null;
  }

  function bestDirectoryMatch(name, confidence) {
    if (!name || !workspace?.customers?.length || Number(confidence || 0) < 0.65) return null;

    const ranked = workspace.customers
      .map(customer => ({
        customer,
        score: candidateScore(customer.name, name)
      }))
      .sort((a, b) => b.score - a.score);

    const best = ranked[0];
    const second = ranked[1];
    if (!best) return null;

    const threshold = confidence >= 0.85 ? 0.76 : 0.86;
    return best.score >= threshold && (!second || best.score - second.score >= 0.07)
      ? best.customer
      : null;
  }

  function applyVision(result) {
    if (!result) return false;

    const confidence = Number(result.confidence || 0);
    const match = bestDirectoryMatch(result.recipient_name, confidence);

    if (result.carrier && !$("receiveCarrier").value) $("receiveCarrier").value = result.carrier;
    if (result.tracking_code) $("receiveTracking").value = result.tracking_code;
    if (result.recipient_address) intakeOcrAddress = result.recipient_address;

    if (match && !result.needs_review) {
      $("receiveCustomer").value = match.id;
      hideInlineCustomer();
      intakeOcrName = match.name;
      $("processingText").textContent = match.name;
      $("processingDetail").textContent = result.tracking_code
        ? "Vision matched customer · tracking captured"
        : "Vision matched customer";
      return true;
    }

    $("receiveCustomer").value = "";
    const safeName = confidence >= 0.65 ? String(result.recipient_name || "").trim() : "";
    intakeOcrName = safeName;
    showInlineCustomer(safeName);
    $("processingText").textContent = safeName || "Name not clear";
    $("processingDetail").textContent = result.tracking_code
      ? "Review customer · tracking captured"
      : "Review customer before saving";
    return true;
  }

  const input = $("packagePhoto");
  if (!input) return;

  input.onchange = async event => {
    const file = event.target.files?.[0];
    if (!file) return;

    $("receiveResult").textContent = "";
    $("receiveNewCustomerEmail").value = "";
    $("receiveNewCustomerPhone").value = "";
    intakeOcrText = "";
    intakeOcrName = "";
    intakeOcrAddress = "";

    try {
      $("processingBox").classList.remove("hidden");
      $("processingText").textContent = "Reading package…";
      $("processingDetail").textContent = "";

      const original = await readFileDataUrl(file);
      const uploadImage = await resizeDataUrl(original, 1600, .82);
      const visionImage = await resizeDataUrl(original, 1800, .90);
      const ocrImage = await resizeDataUrl(original, 2800, .96);

      intakePhotoDataUrl = uploadImage;
      $("packagePhotoPreview").innerHTML =
        '<img src="' + intakePhotoDataUrl + '" alt="Package photo">';

      let visionResult = null;
      try {
        visionResult = await analyzePackageWithVision(visionImage);
      } catch (error) {
        console.warn("Vision engine unavailable", error);
      }

      if (visionResult) {
        applyVision(visionResult);

        const support = await readPackagePhoto(ocrImage);

        if (visionResult.carrier) $("receiveCarrier").value = visionResult.carrier;
        if (visionResult.tracking_code) $("receiveTracking").value = visionResult.tracking_code;
        if (visionResult.recipient_address) intakeOcrAddress = visionResult.recipient_address;

        if (visionResult.needs_review || Number(visionResult.confidence || 0) < .78) {
          $("receiveCustomer").value = "";
          const safe = Number(visionResult.confidence || 0) >= .65
            ? String(visionResult.recipient_name || "").trim()
            : "";
          showInlineCustomer(safe);
          $("processingText").textContent = safe || "Name not clear";
          $("processingDetail").textContent = $("receiveTracking").value
            ? "Review customer · tracking captured"
            : "Review customer before saving";
        } else if (!support.match && !$("receiveCustomer").value) {
          showInlineCustomer(intakeOcrName);
        }
      } else {
        const support = await readPackagePhoto(ocrImage);
        intakeOcrAddress = support.address || "";
        if (!support.match && !support.candidate) {
          $("processingText").textContent = "Name not clear";
          $("processingDetail").textContent = $("receiveTracking").value
            ? "Vision not connected · tracking captured"
            : "Vision not connected · enter customer";
          showInlineCustomer("");
        }
      }
    } catch (error) {
      console.error(error);
      $("processingBox").classList.remove("hidden");
      $("processingText").textContent = "Name not clear";
      $("processingDetail").textContent = "Enter customer name and email";
      showInlineCustomer("");
    }
  };
})();

function normalizeResult(obj: any) {
  const base = {
    readable: Boolean(obj?.readable),
    carrier: String(obj?.carrier || "").trim(),
    return_address: String(obj?.return_address || "").trim(),
    recipient_name: String(obj?.recipient_name || "").trim(),
    recipient_business: String(obj?.recipient_business || "").trim(),
    recipient_address: String(obj?.recipient_address || "").trim(),
    tracking_code: String(obj?.tracking_code || "").trim(),
    confidence: Number(obj?.confidence || 0),
    needs_review: Boolean(obj?.needs_review),
    evidence: {
      carrier: String(obj?.evidence?.carrier || "").trim(),
      recipient: String(obj?.evidence?.recipient || "").trim(),
      destination: String(obj?.evidence?.destination || "").trim(),
      tracking: String(obj?.evidence?.tracking || "").trim()
    }
  };

  if (!Number.isFinite(base.confidence)) base.confidence = 0;
  base.confidence = Math.max(0, Math.min(1, base.confidence));

  if (base.confidence < 0.78) base.needs_review = true;
  if (!base.recipient_name) base.needs_review = true;

  return base;
}
