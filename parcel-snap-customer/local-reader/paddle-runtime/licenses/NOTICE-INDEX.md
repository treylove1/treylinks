# Redistributed software and model notices

This directory ships the full exact license and notice texts obtained from installed packages or their official upstreams. It also includes source URLs, retrieval outcomes, exact file hashes, dependency pins, and official model-license evidence. Preserve this directory with redistributed runtime assets. This is a provenance inventory, not a legal opinion.

- PaddleOCR.js 0.4.2: Apache-2.0 declaration in the exact npm package; full license from the official PaddlePaddle/PaddleOCR repository, `PaddleOCR-LICENSE.txt`. The repository's LICENSE includes PaddlePaddle attribution. The package omits its license file; official root NOTICE was requested and returned 404. That 404 is not a claim that every repository subdirectory lacks notices.
- OpenCV.js (@techstark/opencv-js 4.10.0-release.1): full exact installed package Apache-2.0 license, `OpenCV-Apache-2.0.txt`, plus full OpenCV 4.10.0 repository license, `OpenCV-4.10.0-LICENSE.txt`.
- ONNX Runtime Web/Common 1.22.0 and its base WebAssembly runtime: full MIT license, `ORT-v1.22.0-LICENSE.txt`, exact source banner, and complete upstream v1.22.0 `ORT-v1.22.0-ThirdPartyNotices.txt`. The complete upstream notice set is conservatively retained; some listed components are not necessarily linked into this particular browser WASM build. This inventory does not claim every listed component is present.
- Clipper 6.4.2: full Boost Software License 1.0, `Boost-LICENSE_1_0.txt`, and the exact 5,328-byte prefix of the distributed Clipper source, `Clipper-JSBN-source-notices.txt`, retaining Angus Johnson, Timo, Tom Wu and referenced algorithm attributions.
- Bundled Tom Wu JSBN: full intact original-author license, `JSBN-TomWu-LICENSE-http.txt`, retrieved from the exact HTTP Stanford URL cited by the distributed Clipper source. The HTTPS form failed with 502; the successful original HTTP retrieval is explicitly recorded. Its full copyright, permission conditions and disclaimer are reproduced without rewriting or assigning a misleading SPDX label.
- Vite 6.4.1: full exact installed `Vite-6.4.1-LICENSE.md`, including the Vite core MIT copyright/permission/disclaimer and its bundled-dependency notices. The built worker contains Vite's injected preload helper, so Vite is not exclusively build-time for this artifact. The full installed notice collection is retained conservatively; not every listed build dependency is present in the runtime.
- js-yaml 4.1.0: full exact installed MIT license and copyright, `js-yaml-MIT.txt`.
- PP-OCRv6_small detection and recognition ONNX model files: official PaddlePaddle model repositories declare Apache-2.0. `MODEL-LICENSE-PROVENANCE.json` records each official model revision and the exact declared license. Every ONNX/YAML member of both downloaded archives matches the corresponding official repository file by LFS SHA-256 or Git blob SHA-1. Original archive URLs/hashes, member SHA-256 values and official metadata snapshots are included. The full Apache-2.0 terms are shipped in `PaddleOCR-LICENSE.txt`.

No npm SDK or dependency algorithm source was edited. Official source is bundled/minified by Vite. The dedicated-worker transport, input restrictions, fetch integrity guard, XHR denial and runtime configuration are separately authored wrapper code. The original ONNX Runtime WASM bytes are unchanged.

No model was initialized, executed, or tested to assemble this inventory. Reading model file bytes here was solely for provenance hashes. This collection does not independently reconstruct the entire OpenCV/WASM native build or make assurances beyond the official declarations, supplied notice texts, and file matches documented here.
